Install

install.sh copies themes into ~/.config/omarchy/themes. It never replaces a theme that you made.

One theme, no clone

$ curl -fsSL https://bjarneo.github.io/100-themes-day/install.sh \
    | bash -s -- synthwave-day --set

All 100 day themes

$ git clone --depth 1 https://github.com/bjarneo/100-themes-day ~/.local/share/100-themes-day
$ ~/.local/share/100-themes-day/install.sh --all
$ omarchy theme set synthwave-day

Apply with Aether

Select a theme, then select Apply with Aether. Aether downloads colors.toml and the background from this site. It shows a preview and asks before it applies the theme. Install as Omarchy theme adds the theme to the Omarchy theme picker.

Other options: --list, --update, --remove, --link and --force. Run install.sh --help for details.

The palettes use the hues of the Neon ANSI Palette design, with OKLCH lightness values for a light background. Yellow has at least 2.7:1 contrast, and the other colors have at least 3.3:1.

Backgrounds are drawn with canvas scripts in tools/. Omarchy is at omarchy.org.
